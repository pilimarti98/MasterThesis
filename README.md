This project consists of a Master's Thesis for the program Indústria 4.0. Digitalització i IA Aplicada (Ed. 2025-2026) by UPC School. 

The study for the project consists in a simulation of an Emergy Management System for a residential home, consisting of solar panels plus a battery for storing the generated energy.

In order to run this code the file configuration.toml must be filled with the user's data in order to obtain metering data and the properties of the solar panel to simulate.
